# DECISIONS log

- **No Li replication code in repo.** The repo contained only CLAUDE.md and empty data/src/tests dirs. Built everything from scratch. The identity of "Li's 7 stocks" is not in the repo, so `LI_STOCKS` in `src/config.py` is a placeholder (AAPL, MSFT, AMZN, GOOGL, JPM, JNJ, XOM). It is used only to report a comparison-group subset of results; **Sid: edit the list and rerun `python src/evaluate.py`** (cheap). Alternative: skip the group entirely (rejected — subset reporting is cheap and the flag is easy to fix).
- **FNSPID file:** used `Stock_news/All_external.csv` (5.7 GB, headlines) instead of `nasdaq_exteral_data.csv` (23 GB, full articles). We only need headline + timestamp.
- **2023 sealing:** prices are downloaded only through 2022-12-31 unless FINAL=1. FNSPID 2023 headlines are written to a separate sealed file, never scored or loaded without FINAL=1. The last trading day of 2022 therefore has no target and is dropped.
- **FNSPID coverage problem (found 2026-11-07 06:10).** `All_external.csv` (verified, 5.7 GB, 13.06M rows) ends on **2020-06-11**: after the S&P 500 filter it has 635,577 headlines, 2010-2020H1, none for 2021-2022. The test folds 2020 (partial), 2021, 2022 would have no news. Sampling `nasdaq_exteral_data.csv` by HTTP range shows it holds 2013-2023 headlines (incl. 2021-2023). **Decision:** also download `nasdaq_exteral_data.csv` (23.2 GB, verify size+sha256), filter it in chunks (usecols Date/Article_title/Stock_symbol only), union with All_external, dedupe on ticker+trade_date+headline. Alternative (rejected): run 2020-2022 folds with no news, which makes H1-H3 untestable there. Reverses the earlier "use All_external only" choice.
- **Date-only timestamps.** 64% of FNSPID rows have `00:00:00 UTC` = date with no time. Per the timing rule they are treated as "no time" -> NEXT trading day (the UTC date is used as written, not shifted to ET, which would have placed them a day early).
- **Timing details.** Cutoff is strictly after 16:00:00 ET. Trading calendar = SPY dates in prices.parquet (to 2022-12-30). Items whose trade day falls on/after 2023-01-01 or beyond the calendar go to `news_sealed_2023.parquet`; never scored or loaded without FINAL=1.
